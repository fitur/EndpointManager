# ENDPOINT MANAGER

An automation lattice for the estate. Each module governs the machines from
genesis to retirement — imaging, provisioning, the watching of health, and the
quiet enforcement of policy. The crew need not know it runs. It simply runs.

> _"We process the fleet so the fleet need not process itself."_

| `ConfigManager/HPIA/` | Firmware and driver husbandry for the hardware estate. |
